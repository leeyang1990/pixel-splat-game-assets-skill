# 风尽之城 · Windward Citadel

一座位于层岩崖顶的原创哥特城堡。金色古树的树冠从左侧探出，青铜塔尖高过城墙，断桥和石阶把旅人引向门内的暖光。场景由独立的三维高斯资产和摆放数据组成。

## 查看与复用

解压后进入目录，运行 `python3 serve.py --open`。浏览器需要 WebGL2。服务会打印本地地址。预览可拖动或用方向键转动，滚轮缩放。展开画面下方的「展示选项」，再打开「独立资产」即可单独查看和下载 `.splat` 与可编辑数据。点击「余火近景」，从「旅人动作」选择静立、驻足环顾、桥上巡游或抬手探光。点击「粒子」切换落叶、火星和流雾，点击「暂停动效」冻结动作。「导出同帧对照」会冻结时间并提供原始图、像素图和帧参数。

点击「控制旅人」进入跟随镜头。用 WASD 或方向键移动，方向以画面为准。可以拖动旋转、滚轮缩放。靠近余火出现提示后按 E 探光，按 R 回到起点，按 Esc 返回进入前的视图。可行走区域为余火所在的下段石阶和桥面。步道边缘会挡住脚步。

每件资产的二进制、编辑数据、局部边界、原点、材质和挂点在 `manifest.json`。场景读取 `scene.json`，可直接编辑实例的位置、旋转和缩放。塔楼与铜顶分别导出，`roofSeat` 和 `seat` 用于对位。城墙带左右连接点，石桥和石阶记录连接高度，古树和藤蔓使用根部或挂点定位。坐标为 +Y 向上、+Z 朝前，1 单位为一格。三维高斯格式为 32 字节 `.splat` 和 stride-14 JSON。

22 件独立 `.splat` 可供兼容查看器读取静止姿态。动态时将 `emitter` 或角色挂点、材质、动作片段与清单中的 `animationBounds` 一同导入。`particle-motion.mjs` 提供落叶、火星和峡谷薄雾的位移与透明度。`character-motion.mjs` 提供独立角色动作，`scene-motion.mjs` 负责巡游路径和探光事件。人物巡游提供预设路线。主动控制由独立的 `player-control.mjs` 和 `explorer.mjs` 读取场景里的石阶、桥面和余火摆放，处理脚底高度、步道边缘、柱脚碰撞和交互距离。通行面按本场景的台阶和桥面配置。

## 生成源码

本地预览由 Python 3 提供静态服务。重新生成需要 Blender 4.5 LTS 与 Node.js。在包根目录依次运行：

```sh
blender --background --python-exit-code 1 --python src/build.py -- --stage all
node src/generate-effects.mjs
node src/finalize.mjs
python3 tools/check_manifest.py manifest.json
node tools/check-motion.mjs
node tools/check-player-control.mjs
```

`src/build.py` 描述结构与材质，Blender 用于源曲面采样和局部遮挡烘焙。`src/scene.mjs` 描述初始组合，`src/finalize.mjs` 将其写到 `scene.json` 并更新文件指纹。运行时使用 `.splat` 绘制投影后的高斯椭圆，并用同一幅场景帧生成原始和像素画面。

## 画面与验证

`previews/final-pixel.png` 是浏览器最终成片。`previews/final-raw.png` 与其共用相机、姿态、时间及源帧。另附侧视、建筑细部和重点资产图。`previews/windward-motion.mp4` 是实际浏览器渲染的动态短片，展示全景落叶和余火近景的抬手动作。`validation/` 保存检查结果、相机、文件指纹和干净目录重建证据。视觉验收针对本作品的构图与实际显示尺寸。浏览器验证覆盖一台桌面设备，移动端帧率未测。

`validation/player-control-browser.json` 记录浏览器按键、上下台阶、桥缘阻挡、余火触发和动作切换的检查结果。
