# 精细造型、遮挡烘焙与视觉验收

在校准代表资产时读取。品质标准与生产决策见 [品质目标](quality-production.md)；此处落实造型、材质、遮挡与高斯覆盖。参考用于品质迁移时抽取适用的层次关系，用于形体复刻时再对齐具体结构。保持输入与交付简洁，中间保留完成画质所需的制作步骤。

## 代表资产先行

提取参考帧，记录轮廓比例、线脚／连接结构、表面层次、明暗、镜头和最终显示尺寸。优先校准最能暴露风险的样件；没有固定最低数量。缩小到参考中的显示大小后，仍需看清主要轮廓、嵌套结构、明暗分区及识别性装饰。像素级相似度没有匹配镜头和时间时不作为验收结论。

将结构／行为检查与视觉结论分别记录。样件未达到视觉标准时继续修改样件，批量扩展会放大同一缺陷。通过后保存实际高斯渲染截图、对应数据／参数与资产哈希；扩展时保持相同转换规则，再检查组合后的遮挡、材质、效果及比例。质量结论注明范围，代表样件的通过不自动认证所有后续资产或整场完成度。

## 造型和材质

把中等尺度结构做进造型：嵌套线脚、凹槽、窗洞厚度、连接、断面和独立石块。磨损、积水暗部、接缝和植物附着应有明确位置与形状。均匀噪声与提高高斯数量不能补出缺失的结构。

可使用已有 DCC、精细网格、程序化表面或雕刻。当前可复用起点 `assets/mesh-to-gaussians/mesh_gaussians.py` 使用 Blender 的 BVH 射线检测烘焙局部遮挡，再按四边面／三角面的参数域采样。Blender 是制作依赖，运行时只加载导出的高斯。实际验证版本为 Blender 4.5.9 LTS；使用其他版本需检查 API 与输出。

将模块复制到项目 `src/mesh_gaussians.py`，示例复制为 `src/build.py`，`style.example.json` 按项目需要放为根目录 `style.json`。示例提供接口起点，造型与目标质量仍按当前参考制作：

```sh
blender --background --python-exit-code 1 --python src/build.py
```

`Mesh` 提供面、倒角盒、截面和管状表面；`from_blender_object` 可读经过修改器求值的 Blender 网格并由 Z-up 转为 +Y-up。导入路径使用明确的颜色键和面法线，不自动解析任意 PBR／UV 节点树；纹理颜色应先烘焙或在颜色采样器中接入。默认程序化颜色函数可替换，不将某个石材配色变成所有主题的要求。

`sample_mesh(mesh,spacing,ao_samples)` 返回 stride-14 数据、材质区间和烘焙证据；`export` 写出二进制、JSON、量化前后支持范围和元数据。示例不包含通用游戏引擎或训练步骤。已验证的精细样件使用约 .030 单位的基准间距和 12 条遮挡射线，细条按自身参数使用更密网格；具体值随资产尺度调整，不是统一预算。

## 覆盖与明暗

长而窄的面采用沿表面两条参数方向的网格，切向尺度分别对应单元覆盖宽度。完整保存切向／法向旋转，法向厚度保持正。细小面用稳定的单元中心；表面轻微抖动不能留下孔洞，也不应产生整齐的点阵明暗。三角形按长边的分层行采样，避免根据面积设定圆形尺度造成细条断续，也避免按长宽比直接拉伸出越界拖影。

烘焙射线以真实中间形体作遮挡源，保留凹槽、重叠部件和接缝的明暗。记录实际射线数量与遮挡变化范围。当前默认是局部遮挡，不包含完整场景全局光照；它可以结合明确实现的场景灯光和接触暗部使用。

高级运行模块支持按元数据启用世界空间法线照明。此模式要求四元数的局部 +Z 对应采样表面法向；切向尺度在前两轴。仅凭任意 `.splat` 的文件名或最小轴不能推断这项约定。保留预烘焙 RGB 的资产可关闭重照明，避免重复变暗。动态人物法线与中心、协方差使用同一部件变换，非均匀缩放用逆转置法线矩阵。

## 按已确定的像素预算校准出图

目标显示尺寸和关键特征在制作前定义，此阶段检查造型转换后的信息损失。诊断覆盖与照明时保留足够渲染分辨率，可关闭最终限色，例如 `pixelArt.paletteEnabled=false`；已烘焙的材质色阶仍保留。原始高斯中应已看清造型、材质和明暗。再按目标校准内部像素高度、色板、抖动和放大方式。像素化会删减信息，不承担增加细节的职责。检查缩小后的细条、装饰和明暗边界，以及移动时的稳定性。

最后按 [像素出图与同帧对比](pixel-output.md) 检查两个模式实际生效，锁住同一场景帧并查看关键细部。需要分层网格时如实记录粗色块和细像素，不将整体低分辨率与精细信息无损保留同时作为未经验证的承诺。

整场继续验证水面反射、光束、人物、环境间的关系。水面有反射通道不等于已呈现合适的水感；光束存在不等于环境受到照明。分别查看实际形体、材质处理、明暗及动态状态。最终交付对应源码、数据、运行模块和可复现证据，结论按实际覆盖范围表述。
