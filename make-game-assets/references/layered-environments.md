# 精细环境资产的制作与验收

适用于建筑、复杂植被和分层地形共同构成的场景。方法来自《风尽之城》的实际回修。先从造型、采样和材质定位问题，再用已导出的高斯确认效果。把题材、色板和项目参数留在项目里。

## 从代表资产到场景

1. **在游戏镜头里定目标。** 选最常用镜头、一个能揭示厚度或开口的侧向镜头和一个细部镜头。记录资产大致占用的逻辑像素，挑出缩小后仍必读的特征，例如两层窗套、交错的叶簇和岩壁的斜断面。先做能暴露这些问题的单件或小组合。
2. **画清三种尺度。** 大形决定城冠起伏、树冠重心、崖线转折。中等结构负责窗洞深度、分枝层级和岩层退进。小细节在合理位置增强读感，例如檐口反光、枝端叶片、岩脊苔色。分别关掉效果查看原始高斯，确认成片的精细度有三维结构支撑。
3. **按形体分配高斯。** 封闭、相交、非平面的曲面先确认几何和采样面一致。薄窗条、石雕和枝尖提高局部密度，大平面维持稳定覆盖。沿表面切向拉开尺度，法向厚度为正。场景合成明暗用局部遮挡与明确的光源职责，固定照明的树冠可提前着色。
4. **用同一批独立文件组装。** 以底部、挂装位、接口或可站立顶面为局部原点。使用清单里的挂点拼接和复用，场景只保存实例变换、灯光和效果摆放。完成代表资产后，再用同一套材料和结构规则扩展变体。

## 三种可迁移的做法

| 资产 | 建模与材质 | 换题材时保留的关系 |
| --- | --- | --- |
| 建筑 | 先做承重体、墙厚和实际开口。沿开口做有深度差的双层窗套，保留暗底和后退的内构件。沿塔身按截面生成束柱、错缝砌层、腰线和檐部。用连续轮廓、少量突出部和间隙组织塔冠。近景中仍要读到窄条和轮廓时，针对这些面采样。独立屋顶使用同一装配基准。 | 沙漠堡垒可将尖拱换为厚门梁和层叠墙垛。工业舱体可将腰线换为结构箍、窗套换为密封槽。保留主体、连接和装饰三层，以及不同深度的阴影。 |
| 树冠与群簇植被 | 先确定根、倾斜主干、分叉和各枝所支撑的冠层。沿曲线连续扫掠收细的截面，共用相邻环以避免明显接头。将次枝落到叶簇附近。叶簇尺寸、密度、深度和明暗分组，保留看得见枝干的间隙。树皮和冠层分别着色，簇内亮部偏向外露侧，背阴处用同材质暗色。 | 可换为针叶树、珊瑚或发光菌群。保留附着方向、分支主次、疏密和分组色阶，按主题更换外端形状、材质与透明策略。 |
| 悬崖与断面地形 | 先定支撑面和整体崖势。用一系列高度截面组织主岩层，改变半径、横向偏移和折面角度。近邻截面形成岩脊，错开的角点形成斜断面和贯穿裂槽。非平面岩面按烘焙所用三角面分别采样。岩脊少量高光，苔色集中在顶缘或台地。碎岩单出，组合时放在断裂和堆积位置。 | 可换成浮冰、侵蚀砖墙或矿坑。保留层的连续性、侵蚀方向和主次破口。用相邻模块的高低、旋转、宽窄和局部碎块打断重复。 |

《风尽之城》的三个回修判断可直接复用：窗格在原始图已弱时先拉开前后深度并建立材质反差。树冠盖住主建筑时缩放或侧移树及镜头，再调亮度。岩面出现大块黑斑时先对齐采样面和遮挡几何，再调覆盖。对有曲率的岩壁，直接采样非共面的四边面可能与 BVH 所用的三角面不重合。先比较三角化前后的图像，依据重现的问题修改局部网格。

## 按实际画面验收

| 检查 | 操作 | 通过依据 |
| --- | --- | --- |
| 建筑 | 从文件加载一件墙或塔，再组装两个墙段或塔与独立顶盖。看正面、斜侧和主要镜头。 | 转角有厚度，窗内外层和顶部轮廓能分开。挂点匹配，连接处无显眼断面、穿插或不应出现的缝。 |
| 植被 | 单件旋转，再放入背景。看枝端和根部，检查树冠与前景建筑的轮廓关系。 | 根至枝端的连接可信，叶簇有明暗和空隙。主要镜头下树冠不会盖掉最重要的结构。 |
| 地形 | 不同朝向拼放同一岩块并检查近侧边和顶、底。对照有雾与无雾。 | 层理在组合中连贯，斜断面可读。主要镜头和侧向镜头里没有异常黑斑、浮空和难以解释的重复缝。 |
| 像素出图 | 冻结镜头、时间和效果状态，由同一源帧导出连续高斯和目标像素结果。保存逻辑网格、倍率及关键裁切。 | 原始图结构已成立。成片保留必须读到的层级。采用分层网格时核对遮挡后的细节区域和普通区域实际倍率。 |
| 动作与效果 | 以同一镜头比较至少两个时刻、检查淡出与循环。切换效果，检查人物动作开始、峰值、恢复、世界移动和关节。 | 可在该镜头辨认运动，粒子经过遮挡后仍合成正确，效果有明确来源。事件在动作中实际改变材质或灯光。暂停时同一帧可重现。 |
| 独立复用 | 在浏览器或目标引擎逐件独立加载 `.splat`，检查文件指纹、量化后 3σ、挂点、材质及适用的 `animationBounds`。 | 同一份资产能旋转、变换、重复摆放和下载，导出与生成源码一致。动态资产附带动作片段或材质适配。 |

分别记录单件、组合和运行结论。保留通过的镜头、实测显示尺寸、文件指纹和必要的未通过项。数据能读、局部烘焙通过和画面达标分别依赖各自证据。用 [品质目标](quality-production.md) 的标准记录主要差距。具体二进制要求见 [资产约定](asset-contract.md)，动态接入见 [场景材质与动画](scene-runtime.md)。
