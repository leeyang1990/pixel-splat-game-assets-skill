# 品质目标与生产决策

每次制作时读取。此处把“能做出这种完成度”转成可检查的生产目标；算法和示例文件提供实现手段，品质结论来自实际资产画面及复用结果。

## 参考怎样用于新资产

从参考提取可迁移的层次关系：大轮廓如何组织，中等结构如何连接，细节集中在哪里，不同材质怎样区分，亮暗怎样塑造体积，像素密度怎样影响可读性。用户要求换主题时沿用这些适用关系，重新设计内容；明确要求形体复刻时，再对齐其具体结构与比例。

记录参考中物体的实际显示大小与镜头。只看放大的纹理切片会高估细节，只看整场氛围会漏掉单件造型。区分三类目标：单件资产品质、场景组合完成度、游戏运行表现。它们分别需要证据，不互相替代。

只有对话时，将描述落实为形体、材质、照明和游戏显示尺寸，再制作代表样件。允许随样件修正美术规则，保持可追溯；不要用“高品质”一词填满尚未做出的设计决定。

## 定义能观察的品质标准

按当前任务选相关维度，为每项写目标、关键特征和检查视角。以下是决策维度，不是每件物体都要添加的装饰清单，也没有通用的色数、高斯数或最低得分。

| 维度 | 制作时落实什么 | 画面怎样检查 |
| --- | --- | --- |
| 轮廓与体积 | 比例、厚度、转折、负空间、支撑和连接 | 目标游戏尺寸下可识别；适用视角中结构成立，不靠特定背景掩盖缺口 |
| 结构层次 | 大形之内有用途相关的中等结构，关键细节有主次和集中区域 | 缩小后仍能读到层级；增密后的平滑基本体不能代替缺失结构 |
| 材质组织 | 每种材质有形状、深浅色阶及空间分布；接缝、磨损、污渍有位置依据 | 材质可区分；大面有安静区域与成组变化，细节不变成均匀杂点 |
| 明暗与空间 | 方向光、局部凹陷、接触暗部、反光／发光各有明确职责 | 体积、遮挡与接触可读；亮部有层次，暗部保留必要结构 |
| 像素语言 | 轮廓阶梯、色块、细线、留白与目标网格共同设计 | 在原生逻辑像素和显示尺寸检查；识别性线网和叶簇仍可读，移动时按需要检查稳定性 |
| 资产族一致性 | 尺度、结构语汇、材质、磨损和像素密度共享规则，变体有实际差异 | 新旧资产并排、重复摆放与组合后协调；不只比较孤立的大图 |
| 独立复用 | 形体、数据、原点、挂点、状态与布景分开 | 换位置／适用旋转／拼接／挂载后仍成立；文件能脱离展示场加载 |

小于目标像素网格的细节可能消失或闪烁。对识别性特征，提高显示像素、调整特征宽度／对比或简化设计；选择有依据的取舍，不承诺任意小尺寸无损保留全部细节。

## 把目标落实到制作

先组织大形和中等结构，再设计材质分区与关键细节。规则建筑也需要按目标制作厚度、连接、层级与断面；简洁风格同样需要准确比例和有意安排的色块。精细度不等于把所有表面做旧。

表面变化分尺度处理：较大的材质／使用痕迹区域，成组的接缝或斑驳，少量微小变化。分布依据形体、方向、接触和材质语义；随机种子保证可复现，但均匀随机噪声不提供美术组织。植被按枝叶簇、疏密、间隙和前后层次构成，避免只重复等距叶片。

照明同时考虑资产用途。局部烘焙负责单件自身形体，场景接触、投影和透明关系在组合中落实；需换灯／运动的资产采用已接入的动态照明路径。把光束、倒影或发光物体放进场景后，要观察它们与环境的关系，不能仅凭通道存在就宣称完成度相同。

源造型方法按需求选择。距离函数、精细表面与雕刻都能进入同一高斯约定；手段的取舍应保留目标结构和材质信息。先解决缺失的形体或明暗，再解决高斯覆盖与出图损失。

## 代表资产怎样验证

选取能暴露当前主要风险的资产或小组合。覆盖范围与任务匹配：建筑样件不能验证人物形体／动作；实心道具不能验证水面或雾。无需固定件数，也不为未请求的类别制作额外资产。

用实际导出的 `.splat` 加载验证，保留：

- 原始高斯与目标像素成片，以及有意义的关键部位裁切；标明逻辑像素与放大倍率。
- 相机、时间／状态、风格和生成配置、对应资产文件／哈希；透明度配置不同则明确标记。
- 适用的其他视角、组合／重复摆放，以及请求的动画或交互状态。
- 每项标准的观察、图像证据、结论与剩余差距，区分 `pass`、`needs-work`、`unverified`。

现有项目可直接记录这些信息，不必另外建立审批系统。Agent 依据实际证据继续工作，不把品质回修变成额外的用户确认关卡。

技术有效、视觉达到目标、复用／行为通过分别记录。关键视觉项未检查时保持未验证；已见差距时说明差距，不用数据检查通过或平均分掩盖。未匹配镜头／内容的图片不做逐像素相似度排名；换主题时比较对应的品质关系，而非强求布局一致。

使用输入模板时，`quality.criteria` 的每项可记录 `criterion`、`target`、`inspection`、`observation`、`evidence`、`status`。`representativeAssets` 记录样件及它负责验证的风险；`evidence` 指向实际图像／运行记录，`unresolvedGaps` 保留差距。空数组或没有图像的 `pass` 不能作为验收证据。

## 看到差距后回到哪一环

| 现象 | 优先定位与修改 |
| --- | --- |
| 比参考粗、像基本体拼接 | 检查比例、转折、厚度和中等结构；回修造型，不先加高斯或滤镜 |
| 满是碎点、看起来脏 | 检查材质变化是否成组、是否有主次、是否被重复照明；再看抖动和色板 |
| 结构存在但显得平 | 检查法线、凹陷／接触暗部、方向光与明暗分区，排除重复烘焙 |
| 窗线断、叶片糊、边缘有洞 | 对照原始与像素图：原始就坏则改形体／采样覆盖；原始成立而成片丢失则改像素预算／色阶／出图 |
| 单件漂亮、放进场景失衡 | 检查相对尺度、像素密度、共享材质、光照及重复分布；单件数据与场景组合分别回修 |
| 一换角度或状态就失败 | 检查隐藏结构、定向高斯、排序、照明策略、运动变换与边界，不以单帧作为完整结论 |

修正后检查受影响画面及直接相邻的复用关系。达到当前目标后继续生产，不反复执行没有新增信息的检查；仍有缺口则继续校准或如实说明实际限制。

## 扩展与可复用的制作规则

代表资产通过后，将当前项目的轮廓／结构比例、材质分区与色阶、变化尺度、采样规则、灯光策略、显示配置和坐标接口保存在源码与风格配置中。保留通过的样件及证据用于并排对照，避免批量生成时逐渐偏离。

变体应在共享规则内改变用途相关的结构、轮廓或状态，种子变化只能提供其中一部分。扩展时检查资产族与组合；新类别、尺寸跨度或动态效果需重新校准其风险，不把一次样件通过外推为整个生产线已经达到所有目标。

更新通用 skill 时沉淀已证实的决策、诊断和可复用模块；主题造型、色板和镜头属于项目配置。历史样件只证明已验证的范围。要宣称能够稳定复现某一品质，应有实际达到该目标的代表产物、可复现参数及后续扩展的检查，单靠改写文档不能作出此结论。
