# 多场景资产生产与验收

复用二进制布局、导出器、运行模块和验证方法。各场景按题材配置美术规则、灯光和像素网格。先选一个能暴露主要风险的组合样件，再为场景做扩展。

## 组织场景包

| 数据 | 内容 |
| --- | --- |
| `manifest.json` | 资产定义、独立文件、原点、边界、材质、挂点、适用的碰撞与动画 |
| `scene.json` | 资产实例、默认镜头、场景灯光和水面基准 |
| `style.json` | 材质色阶、显示色板、像素尺寸和细节参数 |
| `src/` | 可重建资产的数据与生成器 |
| `previews/` 或 `validation/` | 单件、拼装、同帧对比、播放检查和可重复的命令 |

高级运行模块使用弧度和正交相机。常用字段为 `camera: {yaw, pitch, span, target}` 和 `items: [{id, asset, position, yaw, scale}]`。`span` 是画面高度对应的世界单位。实例 ID 在场景内唯一，`asset` 引用清单中的资产 ID。缩放可用正数或正三元数组。需要控制器时将行为或通行面与美术表现一起交付，碰撞数据保存在适合项目的运行层。

## 在不同题材里复用流程

- **工业与熔流**。先做炉体和熔池，验证机械轮廓、岩石支撑与发光材质。用挂点对齐进料管、出液口和熔流。定睛检查发光区域仍能分辨熔池纹理和金属外沿，随后看火星起点、运动方向和轮廓。复用到设备或魔法机关时保留装配规则，重做材料和发光层次。
- **淹水建筑与植被**。先做一组肋架、薄玻璃、岸石与草丛，留出镜头能看见的水面。水面高度与镜像通过场景参数对齐，沿岸重点检查漂浮、穿插和侧视反射。只给有识别价值的肋条、玻璃边和植株轮廓标记细节范围，实际用画面确认。复用到地下湖或雨夜街道时先确定水体边界和反射主体。
- **悬崖城堡、树冠与角色**。按 [精细环境资产](layered-environments.md) 做城垣分层、树冠明暗、岩层与导航路线。通过单件转动、重复拼装和可玩通路检查比例。记录控制器适用的实际地形。

## 验收

1. 用游戏镜头检查轮廓、主要材质和焦点。近看最易损失的细线，换一个运行允许的视角检查接缝和遮挡。场景首屏露出作品，资产和出图操作可折叠。
2. 用场景实际使用的二进制单独摆放代表资产。旋转、复位、换灯或组合，验证挂点、支撑面、动画包络与原点。可动效果用同一相机比较不同时间。水面要检查镜像基准和侧视边界。
3. 导出同一帧的原始高斯、像素出图、细节遮罩与镜头时间。记录真实源分辨率和像素网格，测到的环境写入报告。
4. 运行以下命令。数据检查覆盖资产及场景引用，视觉和交互需要用实际查看器。总实例高斯数包含同一资产的每次摆放，也包含运行时会上传的隐藏实例。需要限制总量时可在 `manifest.json` 的 `budgets.maxSceneGaussians` 写入项目实测预算。

```sh
python3 ~/.codex/skills/make-game-assets/scripts/check_manifest.py manifest.json
python3 ~/.codex/skills/make-game-assets/scripts/check_scene.py manifest.json scene.json
```
