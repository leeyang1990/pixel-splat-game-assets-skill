# 直接采样与像素风出图

用于能用距离函数描述的新资产，以及希望减少 DCC 往返的程序化制作。此支路与精细网格转换共用高斯数据约定、渲染、动画和游戏接入接口。复杂雕刻、UV 材质或既有模型可继续采用精细表面转换；最终可见资产仍为真正的三维高斯。

## 先确定游戏画面里的像素预算

先定资产用途、镜头、目标逻辑像素尺寸和材质明暗色阶，检查最细窗线、叶片及装饰在该画面中有多少像素，再设几何细节和采样间距。造型误差、遮挡错误、像素数不足分别解决；不以增加全场高斯数代替可读性。

新资产可从 SDF 的盒、圆柱、胶囊、环和布尔运算开始。直接采样适合规则建筑构件、石块、道具和许多有机形；精细表面转换适合已经清楚定义的复杂结构。代表资产通过参考尺寸验收后，再扩展族、变体或 LOD。

## 从距离函数得到真实高斯

可用模块在 `assets/sdf-to-gaussians/`。将三个模块复制到项目 `src/`，示例复制为 `src/build.mjs`：

```sh
node src/build.mjs
```

模块在组件范围内采样近表面单元，将候选点投影到距离函数零面，按梯度建立局部 +Z 朝外的单位四元数，赋予两个切向尺度和正的法向厚度。它输出带旋转和协方差的 `.splat`，不输出方块网格。组件可用不同 spacing，细线不必跟墙面同密度；`maxCells` 与 `maxPoints` 在采样前／过程中控制工作量。

复杂组合先做包围范围判断，再计算细节函数。保留每件独立数据、固定局部坐标和种子；不在游戏帧循环中重新采样静态形状。记录投影失败并丢弃的候选数，检查最终零面残差、法线方向、覆盖孔洞、量化后的 3σ 范围和实际二进制加载；失败计数不等于最终数据无效，也不能只凭残差通过就断言没有漏面。椭球等保守距离估计器保持正确零面，但不宣称是处处精确的欧氏距离。

## 光照按复用方式选择

`sampleSdf` 的两种已实现策略：

| 用途 | 策略 | 交付颜色与限制 |
| --- | --- | --- |
| 固定灯光的微缩场景、静态展示资产 | `baked-ramp` | 按 SDF 法线、局部方向光、阴影步进和近距遮蔽探测，选取材质自身的短色阶，写入每个高斯 RGB；运行时保持预照明，不再叠加同一套照明 |
| 会旋转、换场景灯光的游戏资产与人物 | `world-ao` | 保留法线约定及反照率乘局部遮蔽，交给已有世界空间照明；不把固定太阳永久焊在角色上 |

当前静态样件烘焙的是各资产局部形体，不是完整场景全局光照。近距遮蔽采用四个法线方向探测，并非路径追踪。动态路径的材质色阶／场景阴影仍需按接入渲染器实现与验证。

每种材质拥有自己的深浅色阶；石材、玻璃亮部、植物与暖光分别检查。静态像素风可以在生成阶段先选色阶，让采样点带有明确明暗；这与最后只对连续渐变限色是不同的制作决策。

## 静态像素风导出

`assets/ink-export/ink-resolve.mjs` 提供可独立测试的 CPU 导出处理，不作为实时游戏帧率承诺。可通过高级渲染器的 `alphaCut` 启用实心样件绘制；默认 0 保持软高斯。先检查原始连续高斯，再使用合适的非零阈值检查实心覆盖；不要把此开关无条件套在水、雾、光束等透明资产上。

验证示例采用常规 2× SSAA：以 960×960 绘制高斯，4 个真实子像素样本形成 480×480 中间图；之后再将中间图的 2×2 样本合为 240×240 画素。前者是渲染采样，后者是风格化合并，最多涉及 16 个源样本。不能把读四次同一张最终纹理称作已经实现 4 spp 渲染，也不能把 SSAA、MSAA、路径追踪样本混为一谈。

```js
import {readSurfaceFrame, buildInkFrame} from './ink-resolve.mjs';
renderer.alphaCut = .5; // 仅用于已经验证的实心风格
renderer.render(frozenCamera, frozenSeconds, frozenPoses);
const source = readSurfaceFrame(renderer); // 包含真实材质覆盖 alpha
const result = buildInkFrame(source, {palette, ramps});
```

内部覆盖完整的区域使用样本平均值再限色；轮廓处通过覆盖样本投票确定物体主色，再从该材质色阶选较深的一档。没有合适深色时保留主色，不强塞黑边。最后仅做整数最近邻放大。示例让所有输出颜色仍落在色板内；这是本管线的选择，不声称逐字复刻参考代码的边缘混色。

透明水、倒影、光束和可动人物继续使用游戏已有材质与动画通道。组合进统一风格时，再验证透明效果、遮挡和颜色；静态实心样件通过不代表这些效果也已验证。保留 [原始与像素同帧比较](pixel-output.md)，以及适合细窗格、叶片的分层像素模式。
